Conditions: (a) bump the counter at every mutation site: catalog_mut, all three Arc::get_mut sites (system.rs:482, system.rs:529, and star_search.rs:816, which the hunter missed), and the whole-catalog swap at session.rs:309 (or also compare Arc::ptr_eq); (b) build the set from has_position stars within R, read drawn() fresh each frame, keep index order; (c) skip building the set when d0+0.5 > R (between galaxies), so it isn't rebuilt every frame for nothing.
