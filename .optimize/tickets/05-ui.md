# 05 Interface: info panel, labels and egui

**Why:** with Earth selected and the full info panel open, draw_hud alone costs 3.4 ms a frame.

**Profile (trace, ms/frame):** hud::draw_hud 3.41 (earth_look, max 6.8), 0.40 (rsg_look), 0.32
(fly); egui context pass total 3.8 (earth), 0.84 (rsg_look); egui tessellation 0.17; egui
process_output 0.18; overlay::compute_markers 0.33 (earth), 0.15 (nebula).

**Questions:** what in the info panel is recomputed every frame (body physical values, climate /
temperature / habitability calculations, counts of moons/planets walking the whole catalog,
formatting, i18n lookups, `format!` into new Strings)? Could it be cached per selection and refreshed
only when the values it shows can change? (Values that change with time, such as distance, must
still update every frame exactly as now.) Labels/markers: per-frame allocations, projecting every
object, sorting.

**Paths:** `crates/se_engine/src/hud.rs`, `overlay.rs`, `skin.rs`, `i18n.rs`, `script_gui.rs`,
`messages.rs`, `wiki.rs`, `star_search.rs` (only what runs per frame), and the se_core functions the
info panel calls (climate, body_params...).

**Bench:** `bash .optimize/bench/all.sh OUT space earth` (both have Earth selected with the info
panel).
