# SpaceEngine .sc catalog vocabulary

Generated by `scratchpad/sc_vocab.py` from the extracted catalogs. 62 .sc files, 34988 top-level tag instances, 14 distinct tags, 5 .csv files, plus `atmospheres.cfg`.

## Method and parser model as implemented

- Tokens: strings `"..."` (with `\"` escapes), `{`, `}`, `(`, `)`, `,`, bare words (numbers, bools, identifiers), `//` line comments, `/* */` block comments (dropped).
- Statement: `KEY arg*` where args are the tokens on the same line as KEY; an optional `{ body }` follows, on the same line or the next line. Body contains statements. Top level is the same grammar.
- Tag with block and name: `Star "name" { ... }` -> key `Star`, arg `"name"`.
- Value kinds are assigned from the argument tokens: string, int, float, exp-number, bool, number, word, sexagesimal(n) for RA/Dec with n parts, multi-number(n), tuple(...), block, block+name, no-value, mixed.
- Counts are occurrences in the whole corpus. Percentages are relative to the number of instances of the owning tag or block.
- Line numbers are 1-based. Examples are `relative/path.sc:line`.

## Key findings for a parser

- 14 top-level tags in the catalogs (Star, Planet, StarBarycenter, Asteroid, Cluster, Barycenter, DwarfMoon, Comet, Galaxy, Nebula, Moon, Quasar, Spacecraft, DwarfPlanet). `Atmosphere` appears only in `atm/atmospheres.cfg`.
- The `{` almost always sits on the line after the key (about 49.5k cases, 9 on the key line). Allow both.
- Bare data rows occur without a key: `PeriodicTermsSecular` / `PeriodicTermsDiurnal` blocks in planets/SolarSys.sc, Moons-small.sc, ExoPlanets, etc. contain lines like `-2.11, -0.91, +1.91,  24.62,  45137.2, 0,` and `0, 0, +0.00993822, ...`. The parser sees a numeric "key" (`0`, `-2.11`). Treat such lines as rows of a list block.
- Commas: inside tuples (`Color ( 30 , 144 , 255 )`, `Quat ( ... )`, `Axis ( ... )`, ~91 tuples) and as list separators in the data rows above. Tuples without commas also exist.
- `//` comments follow values on the same line (~19k cases). Strip comments before splitting values.
- Names contain `/`, `*`, and `//`-like text (`"HD 221356D/** GZA 1B/..."`, `"HIP 85365A/* 47 Oph"`). Lex strings before comments.
- `/* ... */` block comments (28, 25 spanning lines) wrap whole commented-out entries, e.g. `/* Likely not a cluster Cluster "NGC 1252" { ... } */` in clusters/Open.sc.
- Escaped quotes `"`: none in the catalogs. Keep support anyway.
- Dec sexagesimal can be negative (`Dec -34 15 28.6`, ~5.4k), signed positive (`Dec +69 40 57`), 2-part (`Dec -29 53`). RA/Dec also appear as plain decimals (`RA 18.71222875`) in the same file.
- Exponent numbers (~1.2k) include 3-digit exponents: `1e-006`, `1.108e+08`, `7e13`.
- Statement-level errors: no unclosed braces, no stray `}`, no keys without values in the catalogs.
- Duplicates: same key twice in one block (e.g. `Clouds` in Planet entries, `Radius` in Planemo.sc), and same Tag+Name defined more than once, sometimes within one file (e.g. `Star "HD 168443 c"` 3x in BrownDwarfs-cand.sc). Decide: last wins or error.
- Empty `{ }` blocks exist (8, e.g. `AccretionDisk`).
- All 62 .sc files use CRLF. 22 files contain non-ASCII bytes. No BOM found.
