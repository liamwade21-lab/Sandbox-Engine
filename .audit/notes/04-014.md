# 04-014 grid on smooth lit discs (done)
- Cause: each terrain node's normal map stored whole body-frame normals in RGBA8 (2/255 steps), so the sphere's own curvature was quantised; near the terminator, where n.l is small, the steps and the bilinear filter made a diagonal ~10 px checker (Saturn and Kepler-10 b from orbit). Shading with the smooth up vector instead removed it (sat3.png), which isolated it.
- SE: tangent-space node normal maps (bump_to_norm_planet.glsl) are flat on a smooth body, plus PlanetUVShatter jitter (already ported as `node_map_uv`).
- Ported: terrain.rs `encode_normal_offset` stores the normal's departure from the texel's smooth direction, square-root encoded (finer steps on gentle slopes); mips average the offsets; planet.wesl `ground_normal` adds it back onto `normalize(in.body_dir)`.
