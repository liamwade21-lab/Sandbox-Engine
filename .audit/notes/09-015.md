# 09-015 Memory limits and caches
- SE: main-def.cfg Memory (VideoMemoryStrategy 1, VideoMemorySize 3072, VideoMemoryReserved 50, RAMSizeMax 8192, RAMSizeMaxPercentage 85, CacheSize*). FUN_14030b0e0 logs "Total/Available/Max SE RAM" (Max = min(total x pct/100, RAMSizeMax), GlobalMemoryStatusEx); FUN_14030aae0 logs "Physical VRAM", "Available VRAM" (DISABLED unless strategy 2), "Max SE VRAM ... (max of physical and config)" / "(forced by config)", "System OS VRAM ... (from config)".
- Ported (new memory.rs, `MemoryLimits` from main-def.cfg; log lines in se.log at start, RAM by GlobalMemoryStatusEx FFI, VRAM by graphics.rs's reg query, on a worker):
  - CacheSizeSolarSystems 64: generated planetary systems are freed least-recently-entered first (system.rs `systems_to_unload`, se_core `Catalog::unload_generated`: names/children dropped, records become hidden placeholders so indices stay; revisiting regenerates the same system).
  - CacheSizeLandNode: terrain nodes of all planets together, LRU (terrain.rs), but capped at the port's 1250 (its old per-planet threshold): 10000 took a surface flight from ~50 to ~280 ms a frame (per-node frame costs, not investigated further).
  - CacheSizeStarNode / CacheSizeGalNode: resident procstars / procgalaxies nodes beyond the size go LRU (on top of the existing stale drop; no effect at 50000 / 10000).
  - CacheSizeGalSysModels 32: the generated cluster/nebula systems of galaxies, LRU (was 6, first-key eviction) (procsystems.rs).
  - CacheSizeAtmoModels (0 = no limit): atmosphere models LRU when set (atmosphere.rs).
- No counterpart: the RAM/VRAM caps themselves (the port has no allocator budget; they only feed the log), CacheSizeLandTextures, CacheSizeGalModels, CacheSize{Gal,Neb}ModelsVRAM (the port draws a few model slots, no model cache); SE's "auto" (0) sizes, not decoded (0 keeps the default).
- Also fixed: terrain.rs computed the atmosphere glow once per node per frame; now once per planet.
- Checked: unit tests (reads_main_def_and_reports_like_se, lru_drops_the_oldest, unloads_a_generated_system, least_recently_entered_systems_go_first); log lines in .audit/work/camera/free.png.log (31621 / 12889 / 8192 Mb RAM, 16303 Mb VRAM); frame times vs se-targets/main: Earth surface flight 49.2 vs 51.4 ms median, deep space 4.11 vs 4.09 ms.
