# 10-008 Script triggers and their parameters
- SE: trigger parser FUN_140276ca0 (Object, Button, Dialog, Mode CROSSED/EARLIER/LATER/INRANGE/OUTRANGE, Time, TimeRange, MaxWaitTime, ActivationDelay, AnimateObject, Value, Direction, Pitch/Yaw/RollRange, LonLatRange, Range/RangeKm/RangeRad, Rect, Type); fired by FUN_140276120. `Control|Move` FUN_140275dd0: sums the movement since the start, fires while |sum| is inside RangeKm/Range (pc) and the frame's direction matches `Direction` (|d - n| <= 0.01 |d + n| per axis; camera axes x left, y down, z ahead, read off tut-02's key hints); StopMove when velocity is 0 (FUN_140576090).
- Ported (`scripting.rs`): Direction and the summed user movement (velocity x dt, so a followed body's motion does not count), Range in pc; Time InRange/OutRange with TimeRange; LonLatRange (port body frame); ActivationDelay; Object|Select Type filter; waypoint objects; RollRange for Rotate/Orbit; ChangeFOV Range; Goto Object filter; new kinds GotoCenter, SetTime, SetCurrentTime, ResetFOV, Horizon, Free, Track, Untrack, StopRotate, GUI|Open/Close/SelectObject, GUI|LeftClick (date). Lenient read of SE's own `Direction (0.0, 0.0, s-1.0)` as -1.
- Checked: unit tests (direction rule, lon/lat, parser); `triggers.se` with dev `vel`/`turn`/`fov`/`select`: Control|Move backward then forward, Rotate, ChangeFOV, Object|Select all met within a frame of the action; 8 tutorials run to "finished" under `--script-auto` (`SE_SCRIPT_AUTO_S=1`), logs list each wait.
- Not ported: Map*/Chart* controls (no universe map or system chart controls in the port), StopOrbit, Input|Button/JoyButton/Custom, GUI clicks/values inside dialogs, class filters in Type ("Planet|Temperate|Terra" checks "Planet"), AnimateObject (parsed only). These time out after 4 s as before.
