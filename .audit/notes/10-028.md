# 10-028 Script music and sound commands
- SE: `playmusic` FUN_14055dd30 ("file" { CrossfadeDuration }, default the `MixDurationScript` variable, main-def 1 s; FUN_140399520 plays, errors when the file is missing), `pausemusic` FUN_14055dc00 / `resumemusic` FUN_14055dad0 (CrossfadeDuration; FUN_140399340 / FUN_140399270). `fadeout` / `fadein` (FUN_1405554e0 / FUN_140554f90) are screen fades (Time, Color, DefTime "guifadeout"/"overlayfadeout"/...), not music: ported under 10-006. `setaudiodevice` FUN_140555a90.
- Ported: `music::ScriptMusic` requests from the runner; the driver cross-fades to the named track (found as `music/<file>` or by file name anywhere under music/) over the given time or 1 s, fades out and pauses on PauseMusic (kept, not removed), resumes and fades in on ResumeMusic; when the script's track ends the shuffled playlist carries on. Respects the user's music switch (requests are dropped while music is off).
- Checked: build/tests; both tracks the tutorials name (tut-05 "Lokijar - Quasar Medusa.ogg", tut-07 "Water Drips - Deep Space Journey.ogg") resolve in the VFS the way the driver looks them up (`script_survey music`); tut-05/07 run through their PlayMusic lines. Playback was not listened to (test runs use SE_NO_MUSIC, and the port must not make sound on the owner's machine).
- Not ported: SetAudioDevice (the port uses the default device; logged).
