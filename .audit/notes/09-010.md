# 09-010 High-resolution screenshot tool
- SE: seScreenshotTool (FUN_140224450: `ScreenshotTileRes` 1024, 512..1024 step 16; `ScreenshotLandLOD` 0; target 8000 x 4000; max dimensions 0xffff). FUN_140221d70 logs "Starting high-resolution screenshot rendering: %i x %i, %i x %i tiles of %i x %i", names `mosaic%05i.%S` in `screenshots-hd/`, pauses time, and when the target is wider than the window keeps the window's horizontal FOV (fov' = 2 atan(tan(fov/2) a_win/a_target)). HiresScreenshot = Shift+F11 (key table FUN_1405ba8f0 entry 6, VK_F11 with Shift). Dialog: Target resolution, Max dimensions, Max size in memory, Tile resolution, Tile count, Scale stars, Wait loading completeness, "Too big resolution!", "Cannot finish loading current tile; ...", "This tool can only be used in 2D mode with perspective projection...".
- Ported (screenshot.rs, shared views in capture.rs): Shift+F11 or Settings > Display "High resolution screenshot" opens the dialog; Start renders the tiles with one offscreen camera (a `SubCameraView` of the full frame per tile, the main camera's exposure / tone shader / colour correction), reads each back (gpu_readback) into one RGBA8 image, saves it on a thread as `<Pictures>/SpaceEngine-rs/screenshots-hd/mosaicNNNNN.<ScreenshotFormat>`. Time paused and LandLOD = ScreenshotLandLOD while it runs (restored after); Scale stars sets the point scale as for a screen of the target's height; Wait loading waits until no terrain node is loading (3 quiet frames, gives up after 1800 frames with SE's message). In a projection mode it shows SE's message and offers the switch. Dev command `hires W H [TILE]`.
- Checked: unit tests (tile grid, FOV rule, limits, numbering); 4000 x 2000 of Earth in 6 x 3 tiles (hires2_small.jpg / hires2_crop.png in .audit/work/capture): no tile seams. Shift+F11 window: ui_display.png.
- Not ported / differs: tiles have no bloom (per-tile bloom showed every tile edge; SE's choice not traced), no lens flares or black-hole lensing (their passes are tied to the main camera). The window keeps rendering normally during the capture. "Open folder" not added.
- README: controls "Shift+F11: high-resolution screenshot (screenshots-hd/mosaicNNNNN in Pictures/SpaceEngine-rs)".
