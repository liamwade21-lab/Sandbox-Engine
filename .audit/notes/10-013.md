# 10-013 Autopilot and targets
- SE keys: ShipSelectTarget T, ShipSelectRefBody P ("Nearest body" / "Influence body" / "Reference body"), ShipRotateTo C, ShipFlyTo Shift+G, ShipWarpTo Alt+G, ShipGoTo G ("Fly or warp to target"). Stages (locale): Preparing/Correcting jump vector, Preparing/Correcting fly vector, Accelerating, Turning for braking, Braking. FUN_140537060 runs the orientation program (constants above, see 10-014); FUN_14051f7b0 the warp program (boost so a jump never crosses the remaining distance in under two frames, "Correcting" when the velocity leaves the line); flags in `seSpacecraft+0xb8` choose main vs retro for braking (0x8000).
- Ported (`ship/autopilot.rs`): target = camera selection (T); reference body cycles nearest / strongest gravity / picked body (P) and sets velocity frame, altitude and holds; Rotate to (done < 0.1 deg); Fly to: turn to the line, accelerate, brake on `sqrt(2 a d)` (retro engines, or turn round first with the turn time allowed for), RCS cancels drift and gravity; Warp to: same with the drive on, physical speed capped, boost limited to half the remaining distance per frame, the warp multiplying velocity relative to the target; Go to warps when flying would take > 300 s. Stops at 4 target radii (the camera's Go to), then Sync velocity. HUD: target, distance, "Autopilot: Warp to target - Braking". Script: `flight target NAME|selected`, `flight ap flyto|warpto|goto|rotateto|off`, `flight ref nearest|influence|NAME`.
- Also fixed: the warp now multiplies the velocity relative to the reference frame (it multiplied the absolute velocity, Earth's orbital motion included).
- Checked: unit tests (point-mass Fly to and Warp to over Earth-Moon, no overshoot); runs: Dragonfly from 2000 km over Earth warps to the Moon, stops 6918 km from its centre (`warp_c.png`, log stages); Fly to the Moon from 10000 km (`fly_*.png`).
- Not ported: SE's fly program internals (FUN_14051efa0 hyperjump interpolation, stop distances, Landing stage), "Fly here"/"Warp here" (map), hyperdrive, target ships (TargetShipID). Guidance math is the port's.
- README controls: T target, P reference body, C rotate to, G / Shift+G / Alt+G go / fly / warp to target.
