# 10-010 Engine exhaust rendering
- SE: ship_engines.glsl + ship_<Type>_engine.glh (Fusion, Chemical, Ion, Ion2, Aerospike, Sphere, Square, SuperDraco_1atm; list built by FUN_1401f4e10). FUN_14048d180 draws each EngineEffect: box [-1,1]^3 scaled by `Size` (half extents, km = cfg m x 0.001), shifted -Size.z and placed at `Pos`/`Rot` (nozzle on +z, exhaust to -z, 2 Size.z long); EyePosTime = eye in box units + time (sim seconds, period 256, per-effect phase index x 0x414a / 7314.7 day); ScaleStep.w = 0.2/0.1/0.05/0.02 for ShipEngineQuality 0-3 (main-def 2); Color = Color x clamp(15 sqrt(level), 0, 20) x hdrShipEnginesBright x BrightnessHDR (BrightnessReal and realShipEnginesBright in "real" mode). A Type without a .glh (Hyper) gets index -1 and is never drawn.
- Ported: `ship_plume.wesl` marches the box (up to 128 steps, RayBoxIntersect, the eight density functions and hash noise verbatim); `ship_assets::plume_box`, `engine_type`, `engine_step`, `engine_brightness`; settings read from main-def.cfg. Front faces from outside, back faces with the camera inside (pipeline key). Sounds of non-drawn effects stay.
- Checked: unit tests (box placement, constants); screenshots `amsb_thrust.png` (Fusion plumes), `df_thrust2.png`, `shuttle_rear.png` (Aerospike jet rows), `shuttle_hover.png` (hover + main).
- The per-ship factor in the brightness (param_5+0x11c0, FUN_14048d180:317) is the ship's fade, the same value FUN_14029f670 gets as Params.z (alpha fade): 1 for a ship in view, so not modelled.
- Assumed: level = the group's spooled level 0..1 (the render-queue writer was not found); time runs on real time (the port's ship clock runs while paused); HDR mode only (BrightnessReal unused). Dithering (off in SE) not ported.
