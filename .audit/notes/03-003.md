# 03-003 Galaxy sprite-model shading and brightness (partial)
SE: galaxy_model.glsl fades a sprite by clamp(dist / spriteSize - 0.5) (main session ported it); emBright = calib (hdr/realGalaxySpriteBright) x galaxy+0x74 x model Brightness x p3 x cfg35b8 x cfg35ac x cfg35ec x galaxy+0xa4 (FUN_14029bdf0:152-154, 209-214), with no per-layer gain and vertex bytes clamped (min(1, intensity)).
Ported now: BULGE_GAIN 0.3 -> 1 (SE has no bulge gain; SE_GAL_BULGE still overrides), vertex colour/intensity clamped like SE's bytes (`sprite_vertex`, also for nebulae), so bright bulge/core sprites no longer exceed 1.
Not ported: SE's absolute brightness chain. SE's emBright does not depend on the galaxy's luminosity or size (every galaxy using a model has the same surface brightness x ModelBright), while the port still calibrates each model to its far sprite's mean surface brightness; the conversion from SE's framebuffer units to the port's is unknown without SE reference captures, and the cfg35ac/35b8/35ec globals were not traced. From inside the Milky Way the port is about 5x brighter than SE's look (white centre, see 03-002). MODEL_MIN_PX area weighting and the edge-faded quad (anti-aliasing) are kept.
Checked: fin_sgr45/sgr10/sgr2.png, fin_mwout.png, fin_m31.png.
