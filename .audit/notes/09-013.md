# 09-013 Projection modes
- SE: main-def `Projection` (`ProjectionMode` 0 perspective, 1 cubic, 2 fish eye, 3 cylinder; `CubeFaceResolution` 512; Fisheye FOV 180 (40..360) / Crop 1 (1..2) / Zoom 1.5 (1..3) / Offset / Warp / FlipX / FlipY / GUIAngle 90; `ShowCubempEdges`, `FitCubemapToScreen`, `CubemapFormat` 0..5 "4x3 Cubemap" .. "6x1 Photoshop DDS plugin"; ranges FUN_140326220). proj_fisheye.glsl: TexCoord = (uv 2 + offset - 1) zoom-scaled, discard r >= crop, ray (cos A, sinA/r y, sinA/r x) + Warp, A = (FOV/2) r; FUN_140596a20 (picking) shows the unflipped sign -1 and aspect on x. proj_cylinder.glsl: lon (2u - 0.5) pi, lat (0.5 - v) pi. No key binds the projection in SE's key table.
- Ported (projection.rs, projection.wesl, views from capture.rs): outside perspective six 90-degree views render raw HDR faces of CubeFaceResolution; a Core3d pass in EarlyPostProcess (before the black-hole lens set) draws the fish-eye / cylindrical resampling or the face mosaic straight into the main texture (no flip, no main-texture read), then bloom, exposure and SE's tone/colour correction run on it as in SE. The main camera renders an empty layer meanwhile (its layers are restored after). In perspective there are no views, components or pass work. Settings > Projection tab (mode, rendering resolution, lens angle, circle crop, zoom, offsets, warps, flips, reset, frame format, "Identify faces" = edges, fit to screen); all keys read from main-def and saved in the settings' Projection block. Env SE_PROJECTION / dev command `projection N`, `cubeformat N`, `fisheye FOV [ZOOM]`.
- Checked: unit tests (fish-eye ray vs the shader, warp/offset/flip/zoom, mosaic layouts, key round trip); fish_a.png, cyl.png, cube.png (Earth), ui_projection.png. 30 still frames at Sirius in perspective, cubic, fish eye and cylinder: no pixel off by more than 8 levels outside the animated selection pointer (same as the baseline build). Frame time perspective 7.46/7.48/7.54/8.57 ms vs baseline 7.21/7.31/7.51/8.49 (alternating runs, noise); fish eye 10.5 ms.
- Not ported: DistortInterface, FisheyeGUIAngle, GUIResolution, LensFlareResolution, ShowBackground (kept and saved): the interface, labels, orbits and lens flares are drawn flat as in perspective. The mosaic face order per named format follows those formats' conventions (SE's placement not traced). Black-hole lensing and the ship warp effect act on the projected frame; point-anchored glows end at face edges; picking still uses the perspective camera.
