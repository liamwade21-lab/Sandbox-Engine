# 07-017 Camera movement modes
- SE: key table FUN_1405ba8f0 binds MoveModeFree/Spacecraft/Aircraft/Game to 1-4 (handlers FUN_1405c7f80, FUN_1405c8050, FUN_1405c80f0, FUN_1405b9420; splash "Free mode" / "Spacecraft mode" / "Aircraft mode"). Mode = camera +0x140c (DAT_1419d5adc), set by FUN_14057a740: entering 2/3 divides the assigned velocity by 10 (DAT_1406d4ec0) into an acceleration (toolbar label "Acceleration", FUN_1405b94a0), leaving multiplies it back; 2<->3 turns the velocity between the universe and camera frames.
- FUN_140576090: mode 1 the keys set the velocity (zeroed each frame); modes 2/3 add dt x input to a kept velocity (inertia), 2 in the universe frame, 3 in the camera frame (turns with the nose). Turning, roll and the auto horizon do not depend on the mode. Z (FUN_1405c4f80) stops at once. Go to sets 0.1 x the arrival speed as the acceleration (FUN_1405c9c80). Keys 1-3 also leave a flown ship; 4 flies the current ship (FUN_1401f6aa0, which resets the mode to Free).
- Save (FUN_1401be6b0/FUN_1401beaa0): MoveMode = mode, or 4 while piloting; Velocity written x100 / read x0.01 in modes 2/3; mode 4 restores the ship by id, else Free.
- Ported (camera.rs `MoveMode`, `set_move_mode`, `move_mode_keys`): keys 1-4 (plain only: Ctrl+1-5 are the flight HUD, 5 auto horizon, 5-0 flight attitudes), splash, the /10 switch, inertial thrust ramped by MoveKeyAccel/Decel, Aircraft velocity turning with the camera, Go to / Land assigned values, toolbar "acceleration" (hud.rs), Movement mode combo in Settings > Camera, script `MoveMode 1-3` (scripting.rs), save.cfg MoveMode 1-4 and the x100 velocity (session.rs), dev `movemode N`.
- Not ported: restoring a flown ship from save.cfg (ships are made per session; a saved 4 comes back as Free, as SE does for an unknown id); script `MoveMode 4`; SE's 0.01 joystick scale (_DAT_141a06d18) in modes 2/3 (gamepads deferred, 07-020).
- Checked: unit tests (move_modes_switch_like_se, aircraft_velocity_turns_with_the_view, session_round_trips); screenshots .audit/work/camera/free.png vs spacecraft.png (same push: Free stops after ~300 km, Spacecraft coasts ~9700 km, toolbar "acceleration 10.000 km/s²"), turn_mode2.png vs turn_mode3.png (same 90 deg turn: Spacecraft keeps heading for the Moon, 6178 km; Aircraft turns away, 22303 km). Keys 1-4 themselves are not scriptable, so not run.
