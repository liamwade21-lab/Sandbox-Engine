# 03-002 Dust of galaxy and nebula sprite models
SE: galaxy_model.glsl:64-69 / nebula_model.glsl:60-65 output absorption sprites as (-rgb * emBright * fade, absBright * fade) x atlas coverage; emission, dust and bulge are drawn in one call sorted far to near (FUN_140334e90, FUN_140333a30) with glBlendFunc(ONE, ONE_MINUS_SRC_ALPHA) (FUN_14029bdf0:194, FUN_1402b3020:295); absBright = model Transparency x p1 (galaxies) or x b (nebulae), see 03-003. Vertex colour/intensity are bytes: clamp(colour), min(1, intensity).
Ported: one AlphaMode::Premultiplied mesh per model; galaxy_model.wesl returns (-colour * emBright * w, absBright * w) for dust (layer 1) and (colour * emBright * w, 0) otherwise; sprites sorted far to near (`SpriteOrder`, 03-003), so dust only darkens what lies behind it. Dust colour = absParticleColor (Milky Way (0.08, 0.24, 0.48), Transparency 0.5); `dust_strength` multiplier default 1. Intensities clamped to 1 (MW absorption reached 5.5).
Checked: s12.jpg (base | v5): Sgr A* lanes orange-brown without the black core, M 31 lanes fainter than before, M 42 dark dust patches with red rims (the dust colour subtracted from the pink emission).
Not ported: ColorAbsorption is not read (its use in this shader is unproven).
README (status): "Galaxy and nebula sprite models use SE's brightness chain, its far-to-near sprite order and dust blend."
