# 03-002 Dust of galaxy and nebula sprite models
SE: galaxy_model.glsl:64-69 / nebula_model.glsl:60-65 output absorption sprites as (-rgb * emBright * fade, absBright * fade) x atlas coverage, drawn with glBlendFunc(ONE, ONE_MINUS_SRC_ALPHA) (FUN_14029bdf0:194, FUN_1402b3020:295); absBright = model Transparency x p1 (galaxies) or x b (nebulae), see 03-003. Vertex colour/intensity are bytes: clamp(colour), min(1, intensity) (FUN_1402da540 / FUN_1402d9a10).
Ported: galaxy_model.wesl dust branch returns (-colour * emBright * w, absBright * w) with AlphaMode::Premultiplied (= SE's blend; Bevy's tonemapper clamps negatives at 0); emBright and absBright come from SE's chain (03-003), the dust colour is the model's absParticleColor (Milky Way (0.08, 0.24, 0.48), Transparency 0.5). `dust_strength` stays as a multiplier, default 1. Sprite intensities are clamped to 1 like SE's bytes (MW absorption reached 5.5).
Checked: v4_sgr45/sgr10/mwout/m31/orion.png against base_*.png: brown/dark-brown lanes, M 31 lanes as before, M 42 shows dark dust patches with red rims (the dust colour subtracted from the pink emission).
Not ported: SE's BBoxRes cell draw order (all dust is drawn over all emission). ColorAbsorption is not read (its use in this shader is unproven).
README (status): "Galaxy and nebula sprite models use SE's brightness chain and dust blend (darken by Transparency, subtract the dust colour)."
