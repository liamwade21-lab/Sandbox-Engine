# 05-014 comet tails (done; two parts not ported)
- SE: FUN_140484400 draws comet_tail.glsl particle sprites from FUN_1404d4100; FUN_1404858f0 builds the VBO (Particles x 4 corners: random direction, phase bytes, kind 0 gas / 1-255 dust from a 2-octave value-noise fBm); FUN_140485750 sets Length = MaxLength (1 AU/r)^SlopeParam; FUN_140486280 fills missing tail values for every comet (MaxLength from mass, Particles 1000-3000 from MaxLength, GasToDust 0.25, Gas/DustBright U-split of U(0.01,0.05), colours, AbsMagn tn(8,4,-2,20), SlopeParam tn(4,2,2,20)). Uniforms: ScaleTime (Length km, frac(dt/0.6 d), 1-(q/r)^0.25, 1), per-particle colour 5000*CometTailBright*hdrCometTailBright*Bright/N, CometVel km/s, EyePos/SunPos AU (SunPos.w = 1), SunCol.
- Ported: comets.rs (uniforms, lazy particle meshes, SE defaults via se_core::procgen::tail_defaults) and comet.wesl (comet_tail.glsl line by line, HG g=-0.3). The old coma sphere and two tubes are gone; CometTailBright/hdrCometTailBright read from main-def.cfg.
- Port fix needed: the sprite tangent normalises before cross() (render metres overflow f32 otherwise).
- Spawn fix: spawn_missing_comets now waits until the system loader is done (it ran before the loader and could spawn comet bodies twice), spawn_tails gives one tail per comet.
- Checked: Halley 1986-03-10 and Hale-Bopp 1997-04-01 from the side (blue gas tail straight anti-sunward, whiter dust tail curved behind), Halley's coma close up, Halley 2024 (35 AU, no tail), AltairC119 (procedural). Frame times vs baseline in .audit/work/comets/ft_*.
- Not ported: SE's fade-in by the comet's apparent brightness (FUN_1404da600 output x DAT_14080b578, a runtime scale) and the impostor FBO path (EnableCometFBO/EnableCometImpostors); the port draws a tail once it is >= 2 px. Catalog comets draw SE's missing values on a stream seeded by name (SE uses its thread RNG at load). Length capped at 1e4 AU near the star (SE uncapped). NoCometTail is honoured (SE's FUN_140486280 would re-enable it).
