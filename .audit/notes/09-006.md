# 09-006 Settings window
- SE: settings dialog tabs Graphics (groups quality, anti-aliasing, post-effects, tone mapping, lens flares, point sources, planets, volumetrics), Camera, Display, Projection/3D, Controls, Interface, Sound; "Reset settings" -> "Really reset settings?" / "This will reset all settings except controls and restart SpaceEngine".
- Ported (settings_window.rs; the old Settings block left hud.rs, the Graphics window left graphics.rs): one window, F4 / Settings button, Ctrl+F4 / Graphics button open it on Graphics. Graphics: preset, Quality (anisotropy, landscape LOD, tiles per frame, the preset's other values listed), Anti-aliasing (MSAA, FXAA), Post-effects (photo mode, exposure compensation, Brightness, Contrast, Saturation, Gamma, Dithering, bloom), Tone mapping, Lens flares, Point sources (star settings), Planets (illumination saturation, self-emission on/off and brightness `terrain::SelfEmission`, water `terrain::WaterDisplay.show`), Volumetrics. Camera (FOV, auto horizon), Display (window mode, VSync, screenshot format, JPEG quality, save transparency), Interface (language, skin, overlay filters, pointer, FPS, star names), Sound. Reset deletes settings.cfg and restarts the exe with its arguments.
- Checked: window_graphics.png (SE_UI_OPEN=graphics); reset path compiled, not clicked (it restarts the app).
- Not ported: Projection/3D and Controls tabs (no stereo/projection modes or key editor in the port). SE's slider ranges were not traced (port ranges kept). Labels go through i18n.tr with SE's English strings.
