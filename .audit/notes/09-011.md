# 09-011 Skybox / panorama export
- SE: seExportSkyboxDialog ("Export skybox": Cubemap / Cylindrical, Resolution, Image format, Pixel format 8-bit / 16-bit / 32-bit (floating-point), Post-process, Color correction (no HDR!), Save transparency); main-def `Export` `SkyboxFormat "tga"`. FUN_1402b49c0 renders the six faces and writes `export/sky_<face>.<ext>` (faces pos_x, neg_x, neg_y, pos_y, pos_z, neg_z) or, for the "dds cubemap" format, one `sky_cubemap.dds`.
- Ported (capture.rs, writers in screenshot.rs): Settings > Display > Export skybox. Six 90-degree views from the camera (D3D cube convention in the camera frame: +Z ahead, +X right, +Y up, each face an upright picture) read back as RGBA16F; cubemap -> `sky_pos_x..neg_z.<ext>`, "dds cubemap" -> one cubemap DDS, cylindrical -> `sky_cylindrical.<ext>` (2:1, Resolution = height) resampled on the CPU with proj_cylinder.glsl's map. Writers extended (no new dependency or feature): PNG 16-bit, TIFF 16-bit and 32-bit float (SampleFormat 3), DDS A16B16G16R16 (FourCC 36) / A32B32G32R32F (116) and cubemaps; JPEG/TGA stay 8-bit (the dialog offers only what the format holds). Colour correction on = exposure + tone shader + SE's colour correction (sRGB-encoded integers); off = raw linear HDR (float keeps it). Post-process = SE's bloom per face (off by default). Written to `<Pictures>/SpaceEngine-rs/export/`, SkyboxFormat saved in the settings' Export block. Dev command `skybox RES [cyl] [FORMAT|cubemap] [8|16|32] [bloom]`.
- Checked: unit tests (face orientation, panorama map, half floats, row padding, headers); every format/depth written by the ignored test and opened with PIL or parsed (16-bit PNG depth 16, float DDS/TIFF values exact); Earth exports: sky_cyl_nobloom.png seamless.
- Not ported / differs: SE's face orientation and the cylindrical file name were not traced (assumed as above). With Post-process each face blooms separately (edges show). Point-anchored glows (the Sun's) end at face edges. Save transparency writes the cleared alpha (objects' alpha as their shaders write it).
