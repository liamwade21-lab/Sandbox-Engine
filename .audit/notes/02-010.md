# 02-010 Member star names RSC (done)
- SE: FUN_1401c0180 names members `RSC %i-%i-%i-%I64d-%i` (galaxy catalog index, cluster index in the galaxy, level, node number, index in the node), or `RSC %i-%i-%I64d-%i-%i-%i-%I64d-%i` in procedural galaxies (the RC numbers, then level-node-index). Node number = parent x 8 + octant (FUN_140543c70; octant bits 4/2/1 = lower x/y/z half, table 0x1407f4be0).
- Ported: `cluster_stars::{node_number, node_cell, parse_member_name}`; clusters.rs `rsc_prefix` (Milky Way 8514; a catalog cluster by its index among its galaxy's catalog clusters, Omega Cen is RSC 8514-29; procedural ones by their RC numbers) and `resolve_member_names`: an RSC name in a goto/select/look command or the search box generates its node and adds the member to the catalog. procsystems.rs (one line) first promotes the RC cluster of an RSC name; a scripted command waits for it.
- Checked: unit tests (node numbers round trip, both name forms); `goto RSC 8514-29-0-0-7` (.audit/work/clusters/rsc_new.png), `goto RSC 8514-1260-0-0-0` (procedural nucleus, rsc_proc_new.png).
