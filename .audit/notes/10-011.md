# 10-011 Hull material maps
- SE: ship.glsl (defines SPEC, ASPEC, ATRNS, EMIS, DETDIF, DETNRM, THERM, ECL, ENVMAP; shader key FUN_1402c8b20 case 6). Material keys parsed by FUN_1402a1fb0, defaults FUN_1402a3560 (DiffColor/EmisColor/SpecColor 1, EmisBright 1, SpecPower 150, DiffMapAlpha "Spec", BumpHeight/DetBumpHeight 2, DetDiffScale 32, DetDiffMag 0.5, DetBumpScale 32, DetBumpMag 0.25, gammas 1, TempMapMaxTemp 3000), uniforms FUN_14029f200 (AmbientParams, HapkeParams from the lit body, DiffColorScale/Const, EmisColor x EmisBright, SpecColorScale = SpecColor + SpecPower, DetailScale, MapCorrections) and FUN_14029f670 (lights, ThermalParams = design `RadTemp`/1000, `ThermalEmissionShift`). BumpMap/DetBumpMap height maps become normal maps through bump_to_norm.glsl (FUN_1402fd4e0, scale = BumpHeight).
- Ported: `shaders/ship.wesl` is ship.glsl (Lambert/Hapke mix, tangent-space NormMap + two-scale detail normal blend (UDN), two-scale detail diffuse, spec map or diffuse alpha with the normalised Blinn highlight, emissive, thermal glow through SE's Planck table (`blackholes::planck_table`), luma limit 65000), keeping the 4-star lighting with eclipse shadows. `se_core::ship::parse_ship_material` has every key; .sm tangents are used (generated from UVs when missing); BC5 (ATI2) DDS decode added. Opaque materials use a fragment entry point without discard (the discard cost +4 ms on DragonFly through lost early-Z).
- Checked: unit tests (defaults, shared BumpMap/NormMap slot, tangents, bump_to_norm, flags); DragonFly scales/specular/emissive wings (`df_new2.png`), AmS-B radiators glowing (`amsb_thrust.png`), Shuttle (`shuttle_rear.png`). Frame time DragonFly orbit view 11.1 ms vs baseline 10.9 ms.
- Review fixes: back faces culled unless `TwoSided` and never flipped (ship.glsl flips only under ALPHA_TRANSP, a define the exe never sets); default flat normal 127 (0 after `2 v - NORM_ONE`), BC5 z stored the same way; height maps read at 16 bits (bump_to_norm.glsl reads `.a` of R8/R16 textures swizzled R to alpha; every bump/DISP map in the install is L8 or L16, so the grey channel is the same value).
- Assumed: colour maps (diffuse, spec, emissive) are sampled as sRGB (the port's convention; SE reads them raw with gamma 1), detail diffuse and normal maps raw. LightParams.z (light+0x60 of the 0x278-byte light entries, FUN_14029f670) is not written by FUN_1404bf5c0, which fills the ship's lights; the port uses 1. ThermalParams.z is 1 (DAT_14075f7d4) in HDR mode, times config+0x35fc only in the `real` brightness mode.
- Not ported: ENVMAP reflections (`Reflections`/`EnvMap`, SHW_Gold/Silver/Diamond, Skylone), MaterialPBR / ship_pbr.glsl (ApolloEaglePBR), YCoCg-compressed maps (none in the install), back-face culling for non-TwoSided materials (the port draws both sides), Params.w = Exposure x hdrShipModelBright (10-026; `HullUniform.ambient.z` is the slot).
