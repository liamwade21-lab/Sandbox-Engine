# 03-012 Galaxy/nebula display controls (partial)
SE: main-def.cfg GalaxyMagnLimit 7, NebulaMagnLimit 7, GlowMagnLimit 7, AutoGalaxyMagnitude true, ObjectFilters ShowCatGalaxies/ShowCatNebulae; keys `]`/`[` all limits (IncAllMagnCoef), Ctrl stars, Shift galaxies, P reset (FUN_1405ba8f0); locale "Galaxies magnitude limit".
Ported: StarSettings.galaxy_mag_limit / nebula_mag_limit (read from main-def.cfg at startup in setup_galaxies, reset values for P); Shift+`]`/`[` change both, `]`/`[` change them with the stars, P resets; `sync_mag_limit` maps them to the far sprites' and models' reference magnitude (mag_ref = limit + 0.5, i.e. unchanged at 7; procedural galaxies and ellipticals follow). AutoGalaxyMagnitude sets the intergalactic-vision switch (SE_GAL_AUTO still wins); ShowCatGalaxies / ShowCatNebulae false hide catalog galaxies (far sprites and models) / nebulae.
Checked: build, unit test nebula_limit_and_filter_reach_the_far_sprites; keys not exercised in a run (no key injection in the dev commands).
Not ported: GlowMagnLimit (models stay tied to the far-sprite limit so the hand-over does not pop), separate galaxy brightness keys, GUI entries for the limits / Intergalactic vision / Real-or-All filters (hud.rs, procsystems.rs belong to others), saving the limits in the user settings file, the filter on ray-marched nebulae.
