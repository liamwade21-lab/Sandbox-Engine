# 10-007 Script access to settings
- SE: `set` FUN_14055ac90, `setu` FUN_14055ab50, `setforce` FUN_14055aa10, `reset` FUN_14055a8d0, `interpolate` FUN_14055a790, `get` FUN_14055a6a0, `waitvar` FUN_14055a5b0 (met check FUN_14054e040: Value or Range), `savevars`/`restorevars` FUN_14055a530/FUN_14055a4f0; script variables are the config variables registered by FUN_1405a4a00.
- Ported: `script_vars.rs` maps ~50 settings by SE name to the port's resources: ShowOrbits/LabelsMode/ShowMarkers and every Show{Orbits,Labels,Markers}<Kind>, constellation/grid switches, StarMagnLimit, PointOverbright/Scale/Desaturation, StarColorSaturation/Shift, SunIllumSaturation, IllumSaturationAuto, StarPointMethod, MotionBlurLength, TimeScale, FOV, AutoHorizon, ShowSelectionPointer, FPS, TextMode, StarNameMagn, EnableBloom/BloomBright/BloomThreshold, EnableLensFlares/Ghosts/PseudoFlares, LensFlareBright/Scale, PseudoFlareBright, LandLOD, LandTargetRes, ShowProcGalaxies/Clusters/Nebulae, WaypointsOpacity, ShowLabelsWaypoints, and after main's merge GalaxyMagnLimit/NebulaMagnLimit/GlowMagnLimit, ShowCatClusters, ExposureComp (negated as SE keeps it), Brightness/Contrast/Saturation/Gamma (FUN_140326220 registers them), and switches.rs's ShowAtmospheres/Clouds/Aurora/CometTails/EclipseMask, EnableEclipses, EnablePlanetShine, AtmoRingsShadow, AtmoExtinction, AtmoMinWidthPix, AtmoDistanceLimit, AuroraBright. Get logs a value, Reset returns a setting to the port's default (SE: its registered default, FUN_14054f320), SaveVars/RestoreVars cover all mapped settings, WaitVar on them is met live; `LessonPassed` (SetForce) is saved to `<user>/script-vars.cfg` and read back, never in test runs (`settings::scripted`).
- Checked: unit tests (kind filters, persistence parse); `triggers.se` run (Interpolate WaypointsOpacity -> Get 0.30, WaitVar ShowOrbits met); tutorials report the settings they set that the port lacks.
- Not ported (stay script variables): PhotoMode, Exposure, AmbientLighting, ShowWater/AccrDisks/AccrJets/Spacecraft/..., ShowCat*, ShowProcStars/CSPlanets, Unit*, Map*/Chart*, Orbit thickness/marks, PlanetShine*, Eclipse*, magnitude limits other than stars (their owners' files are other packages'). GotoLocation PhotoMode/Exposure/Stereobase: the port has no photo mode, exposure control or stereo view. Reset's SE default value table was not traced.
- Port choice: a script stopped by hand applies its first SaveVars (the port saves settings as they change); a menu scene (SE: its own variable slot, main-def EnableVariableSlots) gives the user's settings back, except TimeScale and FOV, and shows the HUD again when it ends.
