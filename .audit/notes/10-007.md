# 10-007 Script access to settings
- SE: `set` FUN_14055ac90, `setu` FUN_14055ab50, `setforce` FUN_14055aa10, `reset` FUN_14055a8d0, `interpolate` FUN_14055a790, `get` FUN_14055a6a0, `waitvar` FUN_14055a5b0 (met check FUN_14054e040: Value or Range), `savevars`/`restorevars` FUN_14055a530/FUN_14055a4f0; script variables are the config variables registered by FUN_1405a4a00.
- Ported: `script_vars.rs` maps ~50 settings by SE name to the port's resources: ShowOrbits/LabelsMode/ShowMarkers and every Show{Orbits,Labels,Markers}<Kind>, constellation/grid switches, StarMagnLimit, PointOverbright/Scale/Desaturation, StarColorSaturation/Shift, SunIllumSaturation, IllumSaturationAuto, StarPointMethod, MotionBlurLength, TimeScale, FOV, AutoHorizon, ShowSelectionPointer, FPS, TextMode, StarNameMagn, EnableBloom/BloomBright/BloomThreshold, EnableLensFlares/Ghosts/PseudoFlares, LensFlareBright/Scale, PseudoFlareBright, LandLOD, LandTargetRes, ShowProcGalaxies/Clusters/Nebulae, WaypointsOpacity, ShowLabelsWaypoints. - Checked: unit tests (kind filters, persistence parse); `triggers.se` run (Interpolate WaypointsOpacity -> Get 0.30, WaitVar ShowOrbits met); tutorials report the settings they set that the port lacks.
- Not ported (stay script variables): PhotoMode, Exposure/ExposureComp, AmbientLighting, ShowClouds/Atmospheres/Water/Aurora/CometTails/AccrDisks/..., ShowCat*, ShowProcStars/CSPlanets, Unit*, Map*/Chart*, Orbit thickness/marks, PlanetShine*, Eclipse*, magnitude limits other than stars (their owners' files are other packages'). GotoLocation PhotoMode/Exposure/Stereobase: the port has no photo mode, exposure control or stereo view. Reset's SE default value table was not traced.
- Port choice: a script stopped by hand applies its first SaveVars (the port saves settings as they change).
