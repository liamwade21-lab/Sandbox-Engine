# 06-008 comets in procedural systems (done for single stars)
- SE: FUN_1404f9210 gives a single star u%100+100 comets (+0x1d40; 0 for brown dwarfs, lum code 7 letter >= 7, or system flag 0x8000). FUN_1404fc9b0: R = inner planet-zone edge (FUN_14050a890), q = tn_d(U(5,10)R, sigma (outer-R/4)/3, R/4, 2 outer - R/4), Q = tn_d(1.2 SOI, 0.8 SOI/3, 0.4 SOI, 2 SOI) (FUN_140441b80), e = clamp((Q-q)/(Q+q), 0, 0.9999), a = q/(1-e), inc/node/argp/M uniform +-pi; none if 2 outer - R/4 > 0.4 SOI. Name star + "C" + n. Body FUN_140502710 on seeds n*0x21ad+sys*0x2244 / sys*0xc49+n*0x1938: mass 10^U(-20,-8.6) MJ, density tn(500,100,200,3000) -> radius (FUN_1404c8990), albedo tn(0.04,0.01,0.01,0.1), rotation tn(2,1.5,0.1,20) h, tail values FUN_140486280; period with the comet mass.
- Ported: crates/se_core/src/procgen/se_comets.rs (generator, tail defaults, tail particles), se_layout keeps the comet count it already drew, mod.rs emits `Comet "<star>C<n>"` blocks (Mass, Radius, Albedo, rotation, AbsMagn, SlopeParam, CometTail, Orbit tilted like the planets).
- Checked: tests (100-199 comets per single star, q/Q ranges, tail defaults, parse into the catalog); Altair gets 157 comets (generated in 3 ms), AltairC119 at perihelion 2006-10-17 shows its tail (proc_altair_c119.png).
- Not ported: comets of multiple-star components (FUN_1404f9210:614-652, count from a pow() formula), the orbit stream state (the port seeds its own; SE uses whatever its thread RNG holds after the planets), and the composition/0x1210/0x1214 draws (FUN_1401aa500, FUN_14050a5f0, FUN_14050a520) that sit between the body draws on stream b.
