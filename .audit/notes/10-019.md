# 10-019 Engine control model
- SE: key table FUN_1405ba8f0 (keyboard registration FUN_1405b7aa0, mod 1 Shift, 2 Ctrl, 4 Alt): ShipMainEnginePlus/Minus `=`/`-` (and keypad +/-), Retro Shift+, Hover Ctrl+, WarpDrive Alt+; ShipMoveForward/Back/Left/Right/Up/Down W/S/A/D/R/F, ShipTurnLeft/Right/Up/Down keypad 4/6/8/2, ShipTurnCW/CCW E/Q, ShipStopRotation keypad 5, ShipFlightAssist U, ShipLook* Ctrl+keypad, HUD modes Ctrl+1..5 (all letter keys without modifiers). FUN_1405c2690 adds the pressed +/- (and wheel, 0.02 of max per notch, FUN_1405b2620) to three commands clamped to each engine (ship +0xbfc/0xc00/0xc04); FUN_140523240 spools the current levels (+0xbf0..0xbf8); ShipStopEngines (FUN_140409c20) zeroes all three.
- Ported: `Flight.main_cmd/retro_cmd/hover_cmd`, `Ship.main/retro/hover`; = / - keys with Shift/Ctrl; thrusters W/S/A/D or the arrows, R/F or keypad 1/0 (correction engines); turn keypad 8/2/4/6, roll Q/E or keypad 7/9 (the arrows no longer turn); egui's Ctrl+= / Ctrl+- interface zoom turned off at startup; hover thrust and hover plumes follow the hover level; `throttle main|retro|hover X`. The autopilot and Hold altitude keep a signed main/retro command and push up with the hover engines when present. Letter keys, U, F ignore presses with modifiers; Ctrl/Alt + keypad do not turn. The port's X cut and Backspace brake are gone (SE: X ToggleConstellations, now also in flight via `overlay.rs`; Backspace SelectPrevObject); Z stops all three groups.
- Checked: unit tests; `shuttle_hover.png` (HUD main 50% / hover 100%, hover and main exhaust).
- Not ported: the held-key rate (not found; the port's 0.5 of full scale per second); mouse-wheel engine control (wheel stays the chase zoom); "Turn by keys speed" / "Roll by keys speed" / "Turn by mouse speed" settings (settings.rs, not this package); ship HUD modes / look keys.
- README controls (flight, replacing "W/S throttle", "X cut", "Backspace brake", "arrows turn"):
  - `=` / `-` (keypad `+` / `-`): main engines up / down; `Shift+=` / `Shift+-`: retro engines; `Ctrl+=` / `Ctrl+-`: hover engines; `Alt+=` / `Alt+-`: warp drive; `Z`: stop engines
  - `W` / `S` / `A` / `D` or arrows: thrusters forward / back / left / right; `R` / `F` or keypad `1` / `0`: up / down
  - keypad `8` / `2` / `4` / `6`: pitch / yaw (Shift faster); `Q` / `E` or keypad `7` / `9`: roll; keypad `5`: stop rotation
  - script: `throttle X` (signed main / retro), `throttle main|retro|hover X`
