# 10-004 Ship sounds
- SE: FUN_1402a8ed0 reads each EngineEffect's `Sound`, `SoundVolume`/`Volume` (Volume wins); defaults: volume 1, thrusters 0.02; sound by group (FUN_1405693a0): Main/Retro `Shuttle_engine.ogg`, Hover `Shuttle_hover.ogg`, Thruster `Shuttle_thruster.ogg`, Hyper `Starship_warp.ogg`. Playback is SDL_mixer: `seSound::FadeIn/FadeOut` (FUN_140567f30/FUN_140568060, Mix_FadeInChannelTimed/Mix_FadeOutChannel), channel volume (FUN_140567eb0, Mix_Volume) at `SoundVolume`. No positional calls are imported (no Mix_SetPosition/SetDistance/SetPanning): no distance attenuation or panning.
- Ported: `EngineEffect::sound_file`, `sound_candidates`, thruster default 0.02 (se_core ship.rs); `PlumeSpec.sound/volume`; `ship/engine_sound.rs` plays one looping voice per sound file of the flown ship: volume = SoundVolume x min(1, sum of Volume x effect level), the level that sizes the plume (spooled engine, RCS/turn command, warp fraction), faded over 0.3 s; silent outside flight mode.
- Checked: unit tests (defaults, voice mixing); logs show "ship sounds: 3 voices" (Shuttle) and 2 (Dragonfly), files read from data/sounds/spacecraft.
- Not ported / assumed: SE's per-effect channels and its fade times for ship sounds were not traced (the code that calls FadeIn for engines was not found); summing effect volumes stands in for SDL_mixer's channel mixing.
- README: Status "Engine, thruster, hover and warp sounds play by thrust while piloting".
